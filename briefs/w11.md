# Brief w11 — Show HN draft

Read `AGENTS.md` in the workspace root first. Its voice and honesty rules apply.
This brief overrides its file-format section: the deliverable is a content draft.

## Job
Draft a Show HN submission for guitar.solutions aimed at Hacker News. The HN
angle is the ENGINEERING: one person wrote a ~968-page illustrated guitar-tone
book and typeset it entirely with self-contained Python (no third-party
dependencies), rendering print PDFs via headless Chrome, with hand-built inline
SVG diagrams, on a static GitHub Pages site. The free lessons are the demo.

## Inputs (read for facts)
- README.md (build pipeline, editions, page counts)
- assemble.py and bookkit.py (skim: real techniques to cite honestly)
- fragments/reference/lessons.html

## Deliverable
One file: fragments/growth/show-hn.md [NEW] containing:
1. Four title options, each under 80 characters, starting with "Show HN:".
   No hype words. The dependency-free typesetting angle leads.
2. The submission text (150-250 words): what it is, why Python instead of LaTeX
   or InDesign (own the tradeoffs honestly), what is free (four full lessons,
   chapter one, no email), one line that a paid unlock exists without the price.
3. An author first-comment draft (200-300 words): the technical details HN will
   ask about — the markdown-to-HTML pipeline, headless Chrome PDF rendering,
   inline SVG diagrams, the tab-sheet rendering, what was hardest.
4. Five anticipated questions with honest two-to-three-sentence answers,
   including "why not LaTeX," "is this AI-written," and "why is the repo public
   if the book is paid." For the AI question: the honest answer is that AI tools
   are used heavily in the workflow and the author edits and owns every claim;
   do not write a denial.

## Hard rules
- No exclamation points, no em dashes, no marketing vocabulary.
- Every technical claim must be checkable against the repo files you read.
- HN tone: plain, specific, self-deprecating where true, never salesy.

## Acceptance criteria (self-check)
1. All four sections present with the counts specified.
2. Titles under 80 chars each, all starting "Show HN:".
3. Zero unverifiable claims; the AI question answered honestly per the rule.
4. Only fragments/growth/show-hn.md written.
