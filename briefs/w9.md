# Brief w9 — four locked-lesson teaser fragments

Read `AGENTS.md` in the workspace root first. This brief overrides its file-format
section: the deliverables are HTML FRAGMENTS, not lesson markdown files.

## Job
Build four "locked lesson" teaser fragments, one per source lesson. Each teaser
gives a rich picture of what the locked lesson covers while showing NONE of its
playable content (no recipe settings, no substitutions, no tab, no drill
instructions). These sit at the end of each free lesson on guitar.solutions.

## Inputs (content sources — real lessons in this repo)
- workbook/lessons/L12-voodoo-child.md
- workbook/lessons/L23-shine-on-you-crazy-diamond.md
- workbook/lessons/L29-texas-flood.md
- workbook/lessons/L39-come-as-you-are.md

## Deliverable
Four files [NEW]:
- fragments/teaser-voodoo-child.html
- fragments/teaser-shine-on.html
- fragments/teaser-texas-flood.html
- fragments/teaser-come-as-you-are.html

Each file contains exactly this structure (fill the bracketed parts from the
source lesson; keep the classes and order exactly):

<section class="locked-teaser" aria-label="Locked lesson preview">
  <div class="lt-head">
    <span class="lt-eyebrow">SAME ARTIST · IN THE FULL WORKBOOK</span>
    <h3>[Song Title] <span class="lt-artist">· [Artist]</span></h3>
    <p class="lt-tagline">[the lesson's one-sentence tone description, adapted]</p>
  </div>
  <ul class="lt-glance">
    <li><strong>Lesson</strong> [NN] of 50</li>
    <li><strong>Difficulty</strong> [from source]</li>
    <li><strong>Key &amp; tuning</strong> [from source, shortened to one line]</li>
  </ul>
  <div class="lt-rig">
    <strong>The rig it decodes:</strong>
    <p>[the signal chain summarized as one flowing sentence: guitar into effects into amp, from the source's Rig section]</p>
  </div>
  <div class="lt-inside">
    <strong>Inside the lesson:</strong>
    <p>[N] signature moves ([names only, comma-separated]) and three drills ([drill names only]). The full recipe, settings, and tab are in the unlock.</p>
  </div>
</section>

Rules:
- Facts only from the named source file; keep its hedging language when you
  summarize gear ("commonly cited as" etc. may be compressed to "the classic
  account" style phrasing but never sharpened into false certainty).
- Curly typographic quotes. No lyric quotes. No exclamation points.
- Do NOT include any settings numbers, any tablature, or any drill instructions.

## Acceptance criteria (self-check before finishing)
1. Four fragments, each one <section> root, balanced tags.
2. Zero settings values, zero tab characters, zero drill instructions present.
3. Signature-move and drill NAMES match the source files.
4. Difficulty and key/tuning match the source files.
5. Only the four fragment files written.

## Output
The four files. Final message: self-check pass/fail per criterion per file.
