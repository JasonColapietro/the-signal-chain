# Brief w13 — per-lesson OG share-card generator

Read `AGENTS.md` in the workspace root first. This brief overrides its
file-format section: the deliverable is a Python script plus its SVG outputs.

## Job
Write a generator that emits one 1200x630 social share card (SVG) per free
lesson, matching the site's dark house style. These become per-lesson og:image
assets so shared links show the song instead of a generic card.

## Inputs (study for style and data)
- fragments/reference/build_panels.py (the existing knob-drawing code and palette conventions;
  reuse its knob visual language)
- lessons.html (the :root CSS palette hexes: bg #120e0b, panel #1f1812,
  line #3b2f20, cream #f2e7cf, cream-dim #d9c9a8, amber #eb9a26,
  amber-hot #ffb84d)

## Deliverable
1. build_og_cards.py [NEW] at the workspace root: self-contained Python, no
   third-party dependencies, same conventions as build_panels.py. Since these
   SVGs render standalone (not inline in HTML), use LITERAL hex colors, never
   CSS variables, and system-safe font stacks with wide letter-spacing rather
   than webfonts.
2. Its outputs in fragments/og/: og-purple-haze.svg, og-comfortably-numb.svg,
   og-pride-and-joy.svg, og-smells-like-teen-spirit.svg.

Card layout, each 1200x630, background #120e0b:
- Top strip: "THE SIGNAL CHAIN · FREE LESSON" eyebrow in amber, letterspaced.
- Song title huge (fits on one or two lines, cream), artist below in cream-dim.
- Right side or lower band: three drawn knobs (reuse the knob geometry from
  build_panels.py) with the lesson's three most iconic settings and range labels:
  Purple Haze: FUZZ 7-8, GTR VOL 8-9, TREBLE 7.
  Comfortably Numb: SUSTAIN ~7, DELAY MIX 3-4, TONE 4-5.
  Pride and Joy: DRIVE 3-4, LEVEL 6-7, MIDS 6-7.
  Smells Like Teen Spirit: DIST 7-8, TONE 5-6, AMP GAIN 2-3.
- Bottom strip: "guitar.solutions" in cream + "RANGES, NOT GOSPEL" in cream-dim.

## Hard rules
- Valid standalone SVG (xmlns present, no external refs, no CSS vars, no images).
- Settings text must match the values above exactly.
- No exclamation points anywhere.

## Acceptance criteria (self-check)
1. Script runs with python3 and writes the four SVGs to fragments/og/.
2. Each SVG parses as XML and contains zero "var(--" occurrences.
3. Settings labels match the table above.
4. Only build_og_cards.py and the four SVG outputs written.
