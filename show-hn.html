Dependency-free Python for a guitar-tone book.

The public artifact is not the paid manuscript. It is the publishing pipeline: a small Python renderer that turns Markdown, guitar-tab blocks, and generated SVG panels into the self-contained HTML behind guitar.solutions.

Open source-visible repo Read sample input Try four free lessons

python3 -m unittest discover -s tests
python3 build_panels.py
python3 build_lesson_pages.py

Standard-library Python for the public demo path. Chrome is only needed when printing PDFs.

Markdown, not a CMS export

Self-contained HTML

bookkit.py handles the project-specific Markdown subset: headings, paragraphs, lists, tables, callouts, links, inline code, emphasis, and fenced tab blocks.

</section>

Renderer

bookkit.py

The shared Markdown-to-HTML typesetting engine. It escapes source text and emits the book's house HTML/CSS.

Panels

build_panels.py

Plain Python creates amp-setting SVG panels from dicts, no drawing library or image-export step.

Lessons

build_lesson_pages.py

Generates standalone canonical pages for the four complete free lessons.

Public/private boundary

What is not included

The paid chapter and lesson Markdown sources live in a private build repo. That text is the product. This repo exposes the engine, public sample, generated site files, and free lesson generators.

Limitations

Not a general book engine

  • No full CommonMark parser.
  • No notation engine; tab is fixed-width text.
  • No open-source license yet; treat this as source-visible.
  • PDF quality depends on browser print CSS and source discipline.
